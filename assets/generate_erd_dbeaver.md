## Automatically Generate an ERD (Quickest)

If you already have a database with tables and defined relationships, DBeaver can instantly visualize them.
1. Open the Database Navigator panel on the left.
2. Expand your database connection to find the specific Schema or Tables folder you want to visualize.
3. Double-click on the schema name (or the "Tables" node).
4. In the main editor window that opens, click the Diagram tab at the top.
5. DBeaver will automatically read the data catalog and layout your tables along with their existing foreign key relationships.
